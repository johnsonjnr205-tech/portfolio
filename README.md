📖 About
I'm Gift John, a Computer Science student with a strong passion for technology, innovation, and continuous learning. This portfolio showcases my journey in Developer Relations, community growth, marketing, and software development — along with the projects and skills I've built along the way.
✨ Features
Responsive design — optimized for mobile, tablet, and desktop
Animated hero section — typewriter-effect intro text with a blinking cursor
Interactive navigation — mobile-friendly hamburger menu with smooth scrolling
Stats showcase — years of experience, ecosystems, internships, and communities built
Skills & technology tags — organized into clean, pill-style categories
Project gallery — card-based layout highlighting key projects
Social & contact links — custom SVG icons for Email, Phone, GitHub, WhatsApp, Upwork, and X (Twitter)
Working contact form — powered by Netlify Forms, no backend required
SEO optimized — meta tags, Open Graph, Twitter Cards, JSON-LD structured data, sitemap, and robots.txt
Custom favicon — black-and-white "GJJ" monogram brand mark
🛠️ Built With
HTML5 — semantic structure
CSS3 — Flexbox, Grid, custom animations, responsive layouts
JavaScript (Vanilla) — DOM manipulation, typewriter effect, mobile nav toggle
Netlify — hosting, continuous deployment from GitHub, and form handling

🚀 Deployment
This site is deployed on Netlify with continuous deployment connected to this GitHub repository. Any changes pushed to the master branch automatically trigger a new build and deploy.
To deploy your own copy:
Fork or clone this repository
Connect the repo to Netlify
Set the publish directory to the project root
Deploy 🎉
